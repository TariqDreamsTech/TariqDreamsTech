01 · Mission & Overview

Executive Summary & Thesis

Ambica International is a high-volume healthcare and pharmaceutical distribution powerhouse operating extensive multi-tenant warehousing facilities, cold-chain temperature-sensitive medication supply lines, and a nationwide logistics network spanning urban delivery motorcycles, heavy transport trucks, buses, and scheduled air cargo flights. Every single day, hundreds of critical hospital shipments, specialized medicines, and medical equipment move through their pipeline.

Despite the company's enterprise scale, its internal operations had become severely bottlenecked by legacy friction: clipboards, paper carbon copies, disconnected Excel spreadsheets, and fragmented commercial software that never talked to each other. Warehouse managers had no live visibility into delivery trucks; finance teams waited days for paper receipts to clear before updating ledgers; and executive approvals required physical wet-ink signatures routed across executives through office mail.

I was brought on as the Sole Systems Architect & Lead Software Engineer to spearhead the complete digital rebirth of the enterprise: designing, engineering, and launching Dovetail — a unified, cloud-native Enterprise Operations Portal on Google Cloud Run. Dovetail eliminates paper entirely, binds NetSuite ERP to a real-time Postgres mirror, tracks live multi-modal fleet and flight movements, secures document downloads behind a 3-layer OTP vault, and empowers company leadership with a zero-delay glass cockpit.

Architectural Mandate
Build a resilient, single-pane-of-glass operations platform that converts 37 paper-bound operational processes into real-time, deterministic digital workflows without interrupting live healthcare shipments across multiple warehouses and logistics hubs.

03 · System Blueprint

The Dovetail Solution Architecture

Dovetail was engineered from scratch around a decoupled, event-driven microservices architecture deployed on Google Cloud Run. The core architecture separates high-frequency user read traffic from heavy asynchronous background data synchronization:

High-Level Dovetail Architecture & Data Pipeline
React + TypeScript
Tailwind CSS · Vite · SSE live streams · Role-based UI components
API Gateway & Auth
Nginx reverse-proxy · Google OAuth 2.0 · MS Entra ID · HttpOnly JWT
FastAPI Microservices
Python 3.12 · Async SQLAlchemy · Pydantic v2 · 37 Modular domains
Data & Cache Tier
Cloud SQL Postgres 18 · Redis 7 streaming mirror · Cloud Storage

At the center of Dovetail sits an asynchronous execution layer driven by Celery Beat schedulers and Redis brokers. Rather than querying third-party APIs synchronously — which causes unpredictable latency spikes and exposes the portal to NetSuite concurrency throttling — all external system data is ingested continually into an indexed PostgreSQL 18 read-optimized mirror.

Multi-Tenant Domain Isolation
Engineered strict tenant isolation separating warehouse operations, corporate HR, finance controllers, procurement, and executive leadership while maintaining centralized schema governance.
Auto-Scaling Cloud Run Backend
Fully containerized Docker microservices running on Google Cloud Run with per-request dynamic DNS upstream resolution, autoscaling down to zero during off-peak hours and scaling to handle peak shipment surges.

05 · ERP Data Pipeline

NetSuite ERP SuiteQL Asynchronous Mirror Pipeline

NetSuite ERP serves as Ambica's single financial and commercial source of truth. However, querying NetSuite directly for real-time operations dashboards suffers from severe limitations: RESTlet concurrency locks, SuiteScript 1000-row pagination ceilings, and multi-second latency per request that degrades portal UX.

To resolve this, I architected a high-throughput asynchronous SuiteQL ingestion pipeline:

celery_tasks/netsuite_suiteql_sync.py
from celery import shared_task import httpx, redis, asyncio from sqlalchemy.ext.asyncio import AsyncSession from app.core.database import async_session_factory from app.services.netsuite import generate_oauth1_header # Synchronize 10+ core ERP domains every 15 minutes without blocking portal users @shared_task(bind=True, max_retries=3, default_retry_delay=60) def sync_netsuite_inventory_and_orders(self): suiteql_query = """ SELECT item.id AS item_id, item.itemid, item.displayname, location.name AS warehouse_location, itemlocation.quantityavailable, itemlocation.quantityonorder, pricing.unitprice AS wholesale_price FROM item JOIN itemlocation ON item.id = itemlocation.item JOIN location ON itemlocation.location = location.id LEFT JOIN pricing ON item.id = pricing.item WHERE item.isinactive = 'F' """ headers = generate_oauth1_header() response = httpx.post("https://<account>.suitetalk.api.netsuite.com/services/rest/query/v1/suiteql", json={"q": suiteql_query}, headers=headers, timeout=45.0) if response.status_code == 200: records = response.json().get("items", []) # Bulk upsert into read-optimized PostgreSQL 18 mirror asyncio.run(bulk_upsert_inventory_mirror(records)) else: raise self.retry(exc=Exception(f"NetSuite Sync Failed: {response.text}"))

This pipeline continuously mirrors Employees, Vendors, Customers, Inventory Levels, Purchase Orders, and Sales Orders across 10+ operational domains into Cloud SQL PostgreSQL 18. Portal queries run against this indexed mirror in under 18 milliseconds, eliminating ERP downtime risk and unlocking instant live filtering for warehouse dispatchers.

06 · Paperless Operations

100% Digital Document Flow & DocuSign Speedup

In healthcare operations, document delays directly stall supply chains: vendor purchase contracts, capital expenditure requests, and pharmaceutical delivery clearances previously required physical printed copies to be hand-carried across department heads. If the CFO or Medical Compliance Officer was visiting another warehouse, invoices sat untouched for days.

I designed and integrated a complete digital document execution engine powered by the DocuSign REST API:

Multi-Recipient Signing Workflows
Pre-configured approval hierarchies: Requester → Department Head → Controller → CEO. Each recipient signs digitally in strict sequence with embedded browser signing or mobile email links.
Real-Time Signer Velocity Audits
Every document tracks exact timestamps: when the request was generated, when each executive opened the notification, and how many minutes they took to sign. Eliminates bottlenecks with transparent organizational accountability.
Measurable Turnaround Reduction
The transition to automated DocuSign webhooks reduced document completion time from an average of 4.2 business days down to 14 minutes. Dynamic signed PDFs and cryptographic certificates of completion are archived automatically to encrypted Cloud Storage buckets.

Instant Micro-Approvals: Eliminating Small-Request Bottlenecks

One of the most insidious productivity drains in Ambica was not the multi-million-dollar contracts, but the hundreds of small, everyday operational micro-requests: a courier bike driver needing an urgent fuel allowance, a warehouse packer requesting additional cold-chain dry ice, an engineer requisitioning spare conveyor parts, or a branch supervisor requesting 2 hours of technician overtime.

Previously, each of these trivial requests required printing a paper requisition slip, walking it to a manager's office, waiting in line, and often waiting days if the manager was in another facility. Operations frequently stalled over $20 fuel vouchers.

1-Click Multi-Channel Approvals
Employees submit micro-requests directly from mobile or desktop in under 15 seconds. Supervisors receive actionable push notifications with direct [Approve] / [Reject] buttons via email and WhatsApp without logging into complex portals.
Dynamic Escalation & Quota Rules
Configured smart financial quotas: pre-approved allowances under predetermined thresholds auto-clear instantly, while unapproved items escalate automatically to higher department heads if unanswered after 15 minutes.

Integrated Online Meetings & Outlook/Teams Sync (MS Graph API)

Cross-warehouse collaboration previously required managers and logisticians to physically travel hours between hubs for operational alignment meetings. Dovetail integrates directly with Microsoft Graph API (`Calendars.ReadWrite`, `OnlineMeetings.ReadWrite`) to transform operational communication:

1-Click Operational Virtual Meetings
Dispatchers and department heads can launch and schedule Microsoft Teams / Outlook video meetings directly from any shipment, warehouse incident, or PO thread with pre-populated attendee rosters and synchronized calendar invites.
Automated Meeting Agendas & Action Items
Meeting agendas auto-generate from live portal data (e.g., delayed shipments, pending POs), and post-meeting action items convert automatically into trackable Dovetail operational tasks with assigned owners and due dates.
07 · Enterprise AI & RAG

Role-Based Multi-Tenant RAG & AI Intelligence

Enterprise healthcare organizations produce vast volumes of unstructured information: cold-chain SOP manuals, supplier agreements, compliance guidelines (FDA/BIR), and historical customer notes. Generic AI chatbots fail in enterprise environments because they lack security boundaries — an intern querying the system must not be allowed to see executive salary sheets or supplier profit margins.

To solve this, I designed a Role-Based Access Control (RBAC) Filtered Retrieval-Augmented Generation (RAG) Engine:

RBAC-Filtered Semantic Retrieval Flow
1. User Auth Context
Extracts JWT role, clearance level, and department ID (e.g. Warehouse, HR, Exec).
2. Pre-Retrieval Filtering
Applies strict metadata filters before semantic vector search runs.
3. Vector Similarity Search
Embeddings matched only against authorized documents within user clearance.
4. Grounded Synthesis
Claude 3.5 Sonnet generates verified answer cited with source document IDs.

This guarantees that warehouse employees only receive answers regarding inventory storage and packing SOPs; procurement staff retrieve supplier price schedules; and only the CEO and CFO can query organization-wide EBITDA margins and profit forecasts.

Multi-Layer Redis Caching
Queries pass through a two-tier cache: an exact-match embedding cache and a semantic query cluster cache in Redis 7, delivering sub-100ms response times for 70% of routine operational inquiries.
EOI Connector (Ops Intelligence)
Claude LLM monitors whitelisted WhatsApp groups and Gmail inboxes via secure webhooks, automatically classifying incoming messages into tasks, follow-ups, and 12+ risk-tiered alerts surfaced to management in real time.
08 · Zero-Trust Security

3-Layer OTP Cryptographic File Vault

In commercial operations, data leakage is an existential risk: competitors acquiring supplier price matrices, client discounts, or internal salary sheets can devastate business margins. Standard username/password logins are vulnerable to compromised credentials or unattended laptops.

I architected a 3-Layer Server-Side OTP Security Framework enforced on every sensitive file download, financial export, or administrative approval:

Layer 1: Identity & Role Check
Server validates the active HttpOnly JWT session, verifying the user's domain whitelisting (Google OAuth / MS Entra ID) and role permissions before initiating the request.
Layer 2: Ephemeral 6-Digit OTP
A cryptographically secure 6-digit OTP is generated server-side, hashed with SHA-256, and stored in Redis with a strict 10-minute time-to-live (TTL).
Layer 3: 3-Attempt Lockout
The code is delivered to the user's verified enterprise email. The system enforces a strict 3-attempt lockout; any brute-force attempt instantly revokes the session and alerts security admins.
Result: Zero Data Leaks in Production
Even if an unauthorized person sits at an authenticated employee's unlocked laptop, they cannot export financial spreadsheets, download supplier contracts, or access payroll data without access to the employee's secondary secure email challenge.

Dovetail Edge Bridge: Secure Direct Access to Physical On-Premise Servers

A major architectural hurdle at Ambica was their massive on-premise physical file servers and network-attached storage (NAS) housed locally inside warehouse server rooms. These physical servers stored terabytes of historical lab test certificates, cold-chain temperature logs, regulatory compliance archives, and legacy accounting backups. Migrating terabytes of data over commercial lines was cost-prohibitive, yet remote executives and warehouse dispatchers needed instant, reliable access.

I architected the Dovetail Edge Bridge — an enterprise hybrid gateway:

Hybrid On-Premise Server Direct Access Gateway Flow
1. Portal Request
User requests file from physical warehouse server via Dovetail UI.
2. OTP Challenge
Server enforces 3-Layer 6-digit OTP verification before authorization.
3. TLS Reverse Tunnel
Outbound-only secure agent tunnel to physical server (zero open firewall ports).
4. Encrypted Stream
File streamed directly to user in-browser with complete cryptographic audit logging.
Zero Inbound Attack Surface
The on-premise physical server agent establishes an outbound encrypted TLS/WebSocket tunnel to Dovetail on Cloud Run. No inbound firewall ports are opened, protecting warehouse infrastructure from external internet probes.
High-Speed Direct File Streaming
Chunked byte streaming allows users to preview 100MB+ pharmaceutical lab reports and historical PDFs in under 1.5 seconds without downloading the entire file to the cloud portal first.

Azure & Microsoft 365 / SharePoint Direct Enterprise Storage Pipeline

For modern active documentation, Dovetail is deeply configured with Microsoft Azure Cloud Storage and Microsoft 365 SharePoint document libraries via Microsoft Graph API. Instead of storing sensitive enterprise documents in isolated silos:

Direct SharePoint Document Sync
Every approved vendor contract, signed DocuSign PDF, and financial ledger automatically streams directly into structured SharePoint document libraries, organized by /Department/Year/Vendor/ with automated metadata tagging.
Azure Blob Storage & Co-Authoring
Large binary assets and live spreadsheets are synced directly to Azure Blob Storage, allowing multi-departmental teams to co-author Word and Excel files in real-time through embedded Microsoft 365 interfaces.

12 · Lessons & Future Vision

Architectural Takeaways & Engineering Lessons

Designing and building an enterprise system of this complexity as a solo architect yielded critical software engineering principles:

  • Never query enterprise ERPs synchronously: Asynchronous ingestion pipelines into read-optimized mirrors are essential for low-latency, resilient web user interfaces.
  • RBAC-filtered RAG is mandatory for enterprise AI: General-purpose AI models without strict permission boundaries are a severe compliance and security liability.
  • Eliminating paper requires organizational transparency: Tracking exact time-to-sign on DocuSign workflows highlighted bottlenecks and motivated executive velocity far more effectively than manual reminders.
