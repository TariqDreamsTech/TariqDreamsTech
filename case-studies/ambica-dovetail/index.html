High-Stakes Healthcare Bottlenecks

Problem

No margin for error in life-critical medicine delivery.

Before Dovetail, Ambica was paralyzed by legacy paper workflows and disconnected software silos that caused delivery delays, lost orders, and blind transit windows.

4–7 Day Signature Delays

Every purchase order, invoice approval, and capital expenditure required physical paper printouts hand-carried across offices. If an approving director was traveling, shipments sat idle for days.

Stalled Everyday Micro-Requests

Even tiny operational requests — a courier needing a fuel voucher, warehouse staff requesting packing dry ice, or 2 hours of technician overtime — required printed slips and days of supervisor chasing.

Blind Transit Windows

Dispatchers had no live visibility into trucks, delivery bikes, or scheduled cargo flights. When a hospital asked when emergency medicine would arrive, staff had to manually call drivers on mobile phones.

Trapped On-Premise Physical Servers

Historical lab test certificates, batch sheets, and compliance documents were trapped on physical on-premise servers inside warehouse basements, completely unreachable for remote executives.

Out-of-Sync Spreadsheets & ERP

NetSuite ERP data was exported manually into Excel files. Departments worked on conflicting versions, leaving the Founder with outdated financial figures until month-end reconciliation.

Complete Digital Transformation

Solution

“Knowing is better than hoping.”

As the Sole Systems Architect, I designed and engineered Dovetail from the ground up: an autonomous, cloud-native Enterprise Operations Portal on Google Cloud Run that converted 37 manual paper processes into real-time digital workflows.

Instant 1-Click Micro-Approvals (<60s)

Engineered an automated micro-approval pipeline: small daily requests (fuel vouchers, supplies, overtime) route directly to supervisors via push notifications and 1-click email/WhatsApp action buttons, clearing in under 60 seconds.

DocuSign REST Multi-Recipient Automation

Integrated DocuSign webhooks with sequential signing hierarchies (Requester → Dept Head → Controller → CEO). Slashed contract approval turnaround from 4.2 business days down to 14 minutes with exact time-to-sign audit logging.

NetSuite SuiteQL Continuous Pipeline

Bypassed NetSuite rate limits by architecting a Celery Beat + Redis ingestion engine mirroring 10+ core domains (Inventory, POs, Vendors, Customers) into an indexed PostgreSQL 18 read mirror (<18ms queries).

Dovetail Edge Bridge (Physical Server Gateway)

Built a secure hybrid gateway connecting Cloud Run directly to warehouse on-premise physical servers via encrypted outbound TLS reverse tunnels (zero open firewall ports), allowing instant in-browser streaming of terabytes of historical files.

Azure Cloud & SharePoint Direct Storage

Direct cloud archiving into Microsoft SharePoint document libraries with automated metadata classification, versioning, and Azure Blob Storage co-authoring for live multi-user Excel and Word workflows.

3-Layer OTP Server Security Vault

Guards every sensitive file download, payroll export, and vendor contract behind an email-verified 6-digit cryptographic OTP (10-min TTL, 3-attempt lockout) — achieving zero security leaks in production.

Integrated Online Meetings & Teams Sync

Integrated Microsoft Graph API for 1-click Microsoft Teams video meeting creation from operational threads, with automated meeting agenda distribution and post-meeting AI action-item assignment.
