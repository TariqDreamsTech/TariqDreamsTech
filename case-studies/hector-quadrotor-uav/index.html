Hector Quadrotor 6-DOF Flight Control Graph

Unlike ground vehicles with non-holonomic constraints, an aerial quadrotor is an underactuated 6-DOF non-linear dynamic system. Ahsan Tariq implemented a two-tier cascade architecture: an inner high-frequency rate loop (00 ext{ Hz}$) that maintains roll, pitch, and yaw stability, driven by an outer trajectory loop (0 ext{ Hz}$) translating 3D position errors into thrust and tilt commands.

quadrotor_telemetry.py — Live Flight Attitude Logging Python / ROS 
#!/usr/bin/env python3
import rospy
from geometry_msgs.msg import Twist
from hector_uav_msgs.srv import EnableMotors
from sensor_msgs.msg import Imu

class HectorFlightController:
    def __init__(self):
        rospy.init_node('hector_flight_controller', anonymous=True)
        
        # Arm Motors via Service Call
        rospy.loginfo("Waiting for /enable_motors service...")
        rospy.wait_for_service('/enable_motors')
        try:
            arm_srv = rospy.ServiceProxy('/enable_motors', EnableMotors)
            resp = arm_srv(True)
            rospy.loginfo(f"Motor arming status: {resp.success}")
        except rospy.ServiceException as e:
            rospy.logerr(f"Failed to arm motors: {e}")

        # Telemetry Subscribers
        rospy.Subscriber('/raw_imu', Imu, self.imu_callback)
        self.cmd_pub = rospy.Publisher('/cmd_vel', Twist, queue_size=10)

    def imu_callback(self, data):
        # Extract angular rate & linear acceleration telemetry
        ang_x = data.angular_velocity.x
        ang_y = data.angular_velocity.y
        rospy.loginfo_throttle(1.0, f"Attitude Rate: roll={ang_x:.4f}, pitch={ang_y:.4f}")

if __name__ == '__main__':
    controller = HectorFlightController()
    rospy.spin()

Autonomous Smart Wheelchair Indoor Navigation & Doorway Clearance

In parallel with aerial flight, Ahsan Tariq designed an autonomous navigation package for an Electric Smart Wheelchair operating in constrained indoor architectural environments (hospitals, care homes, living quarters). The challenge was maintaining human-centric comfort while traversing tight bash.8 ext{ m}$ doorframes without jerky angular adjustments.

Tight Doorway Passage Envelope

Configured an elliptical footprint inflation model. Prevents false positive obstacle triggers on doorposts while guaranteeing a minimum 0 ext{ cm}$ safety buffer on both wheel rims during passage.

Multi-Room Indoor World Mapping

Built in Gazebo with realistic household furniture, ramps, and reflective tile surfaces. Validates laser raytracing robustness against glass doors and acoustic sonar reflections.

Before vs After: Manual Piloting vs Autonomous ROS System

Comparing unassisted manual operation against Ahsan Tariq's autonomous aerial flight and smart assistive navigation architecture.

BEFORE (UNSTABLE RC FLIGHT)

Vortex Ring Oscillations & Pilot Crashes

Manual quadrotor piloting without an active attitude rate loop resulted in rapid roll/pitch divergence, pilot disorientation, and catastrophic crashes within 30 seconds of takeoff.

AFTER (100 HZ CASCADE PID LOOP)

Stable Hover & Telemetric Waypoint Control

100 Hz inner-loop attitude stabilization coupled with IMU/sonar sensor fusion maintains rock-solid position hold with sub-5cm vertical error, even under simulated crosswind disturbances.

BEFORE (MANUAL STRAIN)

Doorframe Collisions for Mobility-Impaired Users

Patients with limited hand dexterity repeatedly struck door jambs and furniture corners when navigating narrow hospital corridors with traditional analog joysticks.

AFTER (ASSISTIVE COLLISION AVOIDANCE)

Autonomous Corridor Centering & Doorway Passing

LiDAR-based costmaps continuously project safe navigable corridors. The wheelchair autonomously centers itself through door openings with zero collision risk and smooth deceleration.
